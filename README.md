# 哩程玩家工具箱

單一 `index.html`（無相依套件、純前端計算）內含兩個工具，直接用瀏覽器開啟即可；push 到 `main` 會經 GitHub Actions 自動部署到 GitHub Pages（repo 須為 public）。

## 工具一：星宇 × 阿拉斯加 中停哩程計算機

用阿拉斯加航空（Alaska Mileage Plan）哩程開星宇航空「外站出發、免費中停台灣 14 天」單程票的互動計算機。
選一個出發地，立刻列出所有可經 **台北桃園（TPE）／台中（RMQ）** 中停、且兩段大圓距離加總 **≤ 1,500 哩** 的跨國目的地搭配。

## 工具四：玩家面板

- **CPM 價值計算**：現金價、稅金、哩程 → 每哩價值與「該刷卡還是燒哩」判定
- **哩程資產**：記錄五家餘額與到期日（僅存 localStorage），餘額自動帶入哩程兌換分頁
- **存哩目標**：選目標票（快速帶入兌換值）→ 連動餘額算差額 → 估買分成本、需刷金額與達成月數
- **會籍門檻追蹤**：華航積分新制（360/720/1,400）、長榮（30,000 哩起）、星宇（30,000/50,000/120,000）晉升差距

其他：中停計算機每個組合可**記錄兩段有票日期與備註**（存本機）；
頁首**深淺色手動切換**；**列印樣式**（比較表可直接印成 PDF）。

另支援：**分享連結**（查詢狀態寫入網址，個人資料不進 URL）與 **PWA**（可加入手機主畫面、離線可開）。

## 工具三：哩程兌換／升等查詢

華航（華夏哩程）、長榮（無限萬哩遊）、星宇（COSMILE）、國泰（亞洲萬里通）四家兌換查詢。
填入持有哩程即標示「✓ 可換」或「差多少」，支援單程／來回切換。
前三家為區域表（華航、長榮以來回表列、單程約半價；星宇以單程表列）；
國泰為距離表：選兩個機場（內建全球約 50 個航點座標）→ 大圓距離 → 五級距離帶 →
各艙等所需里數（2026/5/1 新表，短途依城市類別以區間顯示）。
另有「比較」模式：選一個目的地（台灣出發，約 28 個常見航點），
同時比較華航／長榮／星宇／國泰（經香港）／阿拉斯加×星宇五個計畫的所需哩程，
各艙等最低者標「最省」，未飛航標「—」。
資料整理自各航官網與公開攻略（2026/07），標「約」者為整理值，以官網為準。

## 工具二：三大航四段票排程器

規劃華航／長榮／星宇「外站出發、經台北折返」現金四段票（A→TPE→B→TPE→A）：
選航空、外站與折返點，排四段日期後自動檢查 2023 新制規則（台北最多一次停留＋一次 24 小時內轉機、票期一年、依序飛行），
內建三種停留模式（去程轉機／回程轉機／兩端皆轉機）與各航司票規提醒，並產生可複製貼進官網「多城市」查價的行程單。

## 規則引擎

- 總距離 ≤ 1,500 哩：經濟 7,500 哩／商務 15,000 哩；超過則為 15,000／50,000 哩
- 1,500–1,600 哩標為「壓線彩蛋區」：2026/07 實測 AS 官網對 KIX/UKB 等壓線組合仍常出低價，頁面上有明確提示以實際查價為準
- 出發地與目的地須為不同國家／地區（港、澳視為不同地區）；同國組合會列在折疊區並說明原因
- 前後段同為星宇；中停台灣最長 14 天；組合雙向皆可開

## 資料說明（2026 年 7 月）

- 航點與航線整理自星宇航空官網及公開航訊；距離由機場座標以大圓公式（statute miles）即時計算，與 AS 系統實際判定可能有數哩誤差
- 已納入 2026 年新航線：台中—東京成田（3/30）、台中—熊本（3/31）、台北/台中—釜山（6/1）、台北—鳳凰城（1/15）
- 高松（TAK）目前僅列台中出發；神戶（UKB）列台北＋台中；宮古島（SHI）、富國島（PQC）標為季節性航班
- 北美、布拉格（2026/8/1 開航）等長程線僅列於距離總表，不參與配對（適用另一張兌換表）；峇里島（DPS）籌備中；高雄（KHH）預計 2026 下半年進駐、航線未定案，暫未納入

## 維護

航網異動時，編輯 `index.html` 內 `<script>` 開頭的 `AIRPORTS` 陣列即可：每個航點一筆
（`code`／`city`／`country`／座標／`hubs`（TPE、RMQ）／`scope`（`asia` 參與配對、`longhaul` 僅列表、`future` 未開航）／`note`、`seasonal` 標籤），距離與配對全部自動重算。
