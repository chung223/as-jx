# 哩程玩家工具箱

單一 `index.html`（無相依套件、純前端計算）內含兩個工具，直接用瀏覽器開啟即可；push 到 `main` 會經 GitHub Actions 自動部署到 GitHub Pages（repo 須為 public）。

## 工具一：星宇 × 阿拉斯加 中停哩程計算機

用阿拉斯加航空（Alaska Mileage Plan）哩程開星宇航空「外站出發、免費中停台灣 14 天」單程票的互動計算機。
選一個出發地，立刻列出所有可經 **台北桃園（TPE）／台中（RMQ）** 中停、且兩段大圓距離加總 **≤ 1,500 哩** 的跨國目的地搭配。

## 工具五：空中動態與即時資訊

導覽分為四大主題：**哩程票玩法**（中停計算機＋兌換表與比較）、**現金票攻略**（四段票排程器＋甜度掃描）、
**空中動態**（雷達／追蹤／METAR／天氣）、**我的面板**（資產／CPM／目標／會籍／匯率／記事總覽）。
舊分享連結（#t=calc 等）維持相容。

- **台灣上空即時航班**（airplanes.live ADS-B，免金鑰、非商業）：以台灣為中心 250 浬的
  即時航機雷達（海岸線 Canvas），含航跡尾巴，點選看航班號、機型、高度、地速，每 45 秒更新
- **桃園進出港看板**：由雷達垂直速率±350 ft/min 判定進場／離場，呼號自動辨識航空公司
- **班機追蹤・機隊觀察**：輸入航班號（IATA 自動轉 ICAO 呼號，如 JX2→SJX2）、註冊號或機型代碼，
  全球定位畫在世界地圖（Natural Earth 110m）上，跨換日線自動處理，30 秒更新＋航跡

- **匯率**（frankfurter.app，免金鑰）：USD/JPY/HKD/EUR 兌台幣現價＋USD 近 30 天走勢圖；
  「AS 買分價換算器」把美分/哩即時換成 NT$/哩，一鍵套用到比價費率
- **機場天氣**（open-meteo.com，免金鑰）：任選航點（預設 TPE）看現況（氣溫、體感、濕度、
  風向羅盤與風速節數）＋未來 7 天氣溫區間與降雨機率圖
- **航空氣象 METAR**（metar.vatsim.net，免金鑰）：真實世界即時電報，前端解碼為
  風、能見度、雲冪、溫度露點、QNH 與 VFR/MVFR/IFR/LIFR 飛航類別，含風切等警示
- **台灣上空即時航班**（airplanes.live ADS-B，免金鑰、非商業）：以台灣為中心 250 浬
  的即時航機雷達圖（海岸線 Canvas），點選看航班號、機型、高度、地速，每 45 秒自動更新
- 皆為瀏覽器直連公開 API、無任何金鑰，離線或被封鎖時顯示友善錯誤
- 另在中停計算機加入**航線示意圖**（Canvas 大圓概略、依甜蜜/壓線/爆表著色）

## 工具四：玩家面板

- **CPM 價值計算**：現金價、稅金、哩程 → 每哩價值與「該刷卡還是燒哩」判定
- **哩程資產**：記錄五家餘額與到期日（僅存 localStorage），餘額自動帶入哩程兌換分頁
- **存哩目標**：選目標票（快速帶入兌換值）→ 連動餘額算差額 → 估買分成本、需刷金額與達成月數
- **會籍門檻追蹤**：華航積分新制（360/720/1,400）、長榮（30,000 哩起）、星宇（30,000/50,000/120,000）晉升差距

其他：中停計算機每個組合可**記錄兩段有票日期與備註**（存本機）；
頁首**深淺色手動切換**；**列印樣式**（比較表可直接印成 PDF）。

另支援：**分享連結**（查詢狀態寫入網址，個人資料不進 URL）與 **PWA**（可加入手機主畫面、離線可開）。

## 工具三：哩程兌換／升等查詢

華航（華夏哩程）、長榮（無限萬哩遊）、星宇（COSMILE）、國泰（亞洲萬里通）四家兌換查詢。
填入持有哩程即標示「✓ 可換」或「差多少」，支援單程／來回切換。
前三家為區域表（華航、長榮以來回表列、單程約半價；星宇以單程表列）；
國泰為距離表：選兩個機場（內建全球約 50 個航點座標）→ 大圓距離 → 五級距離帶 →
各艙等所需里數（2026/5/1 新表，短途依城市類別以區間顯示）。
長榮視圖另有兩個效益最大化工具：「同區換最遠」（各區最遠航點與每千哩程飛行效益，座標即時計算）
與「跨區經台北・外站哩程票檢查」（2025/9/1 新制：分段哩程不得超過跨區總價 — 選起點區／折返區
即自動判定可開或封殺、比分開換省多少哩；亞洲跨區預設整理值可修改，以官網為準）。

「ANA」視圖為 **1.5 段票組合器**：台日來回（經濟 20,000／商務 40,000）加掛一段
日本→台灣單程只 +3,000 哩（開口＋台灣停留規則，星盟長榮/ANA 航班），
選航點與三段日期即檢查開口、日期順序與一年票期，哩程為社群實測整理值。

另有「比較」模式：選一個目的地（台灣出發，約 28 個常見航點），
同時比較華航／長榮／星宇／國泰（經香港）／阿拉斯加×星宇五個計畫的所需哩程，
各艙等最低者標「最省」，未飛航標「—」。
資料整理自各航官網與公開攻略（2026/07），標「約」者為整理值，以官網為準。

## 四段票甜度掃描器（免金鑰・Google Flights）

`.github/workflows/scan-fares.yml` 每天 05:00（台北）自動執行 `scripts/scan_fares.py`：
以 [fast-flights](https://github.com/AWeirdDev/flights)（免金鑰、免註冊）解析 Google Flights 來回票價，
對「外站×折返點×艙等」矩陣組出**雙來回拆票估價**（A⇄TPE＋TPE⇄B，兩張票可直接照訂）
與「台北直飛來回」基準，寫入 `fares.json` 供四段票分頁顯示
（組合 ≤ 直飛 130% 標「甜」，另顯示「加購 A⇄TPE 的成本」）。
註：Google 多城市頁的票價是前端動態載入，初始 HTML 抓不到，故不做單 PNR 多城市價；
頁面附一鍵連結可到 Google Flights 多城市手動複查。

不需要任何 API 金鑰或 Secrets——首次結果可至 Actions →「Scan 4-leg fares」→
Run workflow 立即產生。Google 偶爾會暫時擋自動查詢，該格會顯示錯誤、隔天自動重試。

## 工具二：三大航四段票排程器

規劃華航／長榮／星宇「外站出發、經台北折返」現金四段票（A→TPE→B→TPE→A）：
選航空、外站與折返點，排四段日期後自動檢查 2023 新制規則（台北最多一次停留＋一次 24 小時內轉機、票期一年、依序飛行），
內建三種停留模式（去程轉機／回程轉機／兩端皆轉機）與各航司票規提醒，並產生可複製貼進官網「多城市」查價的行程單。

## 規則引擎

- 總距離 ≤ 1,500 哩：經濟 7,500 哩／商務 15,000 哩；超過則為 15,000／50,000 哩
- 1,500–1,600 哩標為「壓線彩蛋區」：2026/07 實測 AS 官網對 KIX/UKB 等壓線組合仍常出低價，頁面上有明確提示以實際查價為準
- 出發地與目的地須為不同國家／地區（港、澳視為不同地區）；同國組合會列在折疊區並說明原因
- 前後段同為星宇；中停台灣最長 14 天；組合雙向皆可開

## 資料說明（2026 年 7 月）

- 航點與航線整理自星宇航空官網及公開航訊；距離由機場座標以大圓公式（statute miles）即時計算，與 AS 系統實際判定可能有數哩誤差
- 已納入 2026 年新航線：台中—東京成田（3/30）、台中—熊本（3/31）、台北/台中—釜山（6/1）、台北—鳳凰城（1/15）
- 高松（TAK）目前僅列台中出發；神戶（UKB）列台北＋台中；宮古島（SHI）、富國島（PQC）標為季節性航班
- 北美、布拉格（2026/8/1 開航）等長程線僅列於距離總表，不參與配對（適用另一張兌換表）；峇里島（DPS）籌備中；高雄（KHH）預計 2026 下半年進駐、航線未定案，暫未納入

## 維護

航網異動時，編輯 `index.html` 內 `<script>` 開頭的 `AIRPORTS` 陣列即可：每個航點一筆
（`code`／`city`／`country`／座標／`hubs`（TPE、RMQ）／`scope`（`asia` 參與配對、`longhaul` 僅列表、`future` 未開航）／`note`、`seasonal` 標籤），距離與配對全部自動重算。
